# BeepType v0.8.0

**这一版加了「图片传输」：手机选图 → 电脑剪贴板里就是这张图 → 在支持粘贴图片的输入框里自动贴出来。** 图片相关的界面也照这一版重新设计过（统一入口、缩略图可删可续加）。

## 手机端

### 图片传输（新功能）

- **手机选图（可多选）→ 电脑光标处自动出现这张图**：图片写进电脑的系统剪贴板，开着「接收后自动粘贴」时直接贴进当前输入框；
- **先选后发**：选中的图片先进"待发区"（缩略图），**不会立刻发送** —— 发送时机与文字一致：
  - **手动**：点右下角「发送」键（只选了图、没打字也能发）；
  - **自动**：说完话（语音转文字）或手机键盘打完字后的自动发送，**图片会跟着一起发出去**；
- **先图后文**：图片先贴到光标处（不回车），文字随后贴并（按设置）回车一次 ⇒ 两者落在**同一条消息**里；
- **后悔操作**：缩略图右上角的「×」逐张删掉；末尾的「添加图片」继续加；
- **图片不自动回车**：贴完图通常还要配文字，回车交给你自己按；
- 单张上限 **8MB**；手机端会**统一压到 2560px / JPEG q92** 再发 —— 顺带解决了 HEIC/WebP 这类电脑端解不开的格式，体积也小（照片通常 1MB 内）；
- **全程内存、不落盘**（两端都不在磁盘上留图片）。

### 界面（图片相关这一块重新设计过）

- **加图入口全 App 只有一个视觉**（主题色的柔和按钮）：空态时在底行左侧，有待发图片时以同样的颜色/图标出现在**缩略图末尾**（尺寸与缩略图齐平）—— 一眼就能认出是同一个入口，同屏不会出现两个；
- 缩略图 64×64、带浅底与描边（白底截图也能看清边界），× 压在右上角内侧、半透明黑底；
- 附件区与文字区之间有一条细分隔线；加图、删图各给一次轻微震动反馈；
- 视觉主次：加图是次要（柔和底色），发送是主要（主色实心圆）。

## 电脑端

- 新增图片接收：分块接收 → 校验（格式白名单、8MB 上限、块序与字节数一致）→ 解码 → 写系统剪贴板 → 自动粘贴（**不回车**）；30 秒收不齐就丢弃并如实回报；
- **能力协商**：电脑端在 `hello_ack` 里声明 `image` 能力，手机端见到才显示图片入口 —— 所以**旧电脑上（或只升手机时）不会出现一个点不动的按钮**；
- 只升手机不影响原有文字功能；只升电脑则手机端照旧（图片入口不显示）。

## 已知边界（说清楚，免得误会）

- **只覆盖"支持粘贴图片"的输入框**：需要"上传附件"的输入框（如 DeepSeek 网页版、部分工具的附件区）不认，粘贴没反应 —— 图片仍在电脑剪贴板里，是那个输入框本身不接受图片粘贴；
- **图片会进目标电脑的剪贴板历史**（比文本更显眼）—— 这一点如实说明，不做承诺；
- Wayland 等不支持自动粘贴的环境 ⇒ 图片同样退化为"手动 Ctrl+V"；
- 手机相册里的原图不会被删除（只读）；截图会被转成 JPEG（q92，肉眼基本无损）。

## 安装

- **PC**：先退出正在运行的程序，再 `sudo apt install ./BeepType_0.8.0_amd64.deb`（或 `sudo dpkg -i`）
- **手机**：直接覆盖安装 `BeepType_0.8.0_arm64.apk`，**不需要卸载**（与上一版同一把签名）
- 想用图片功能：**两端都要升到这一版**

# BeeType v0.2.4

新增「连接后自动隐藏窗口」设置项，顺手去掉一个会让人困惑的隐性行为。

## 新增

### 设置 → 通用 → 连接后自动隐藏窗口（默认开启）

- **开启**（默认）：手机连上电脑后，窗口先显示 0.9 秒的「已连接」再自动收起到系统托盘——和以前一样。
- **关闭**：窗口一直留在桌面，方便盯着连接状态、管理常用手机。

## 修复

### 窗口"不再自动收回"的怪异行为

以前有个隐形规则：只要这个窗口是**从托盘手动打开**过的（包括为了显示二维码去点托盘），本次运行期间它就被当成"控制台"，之后配对/重连都不再自动收回——而扫码又必须先打开窗口，于是很容易变成"自动收回再也没生效过"。

现在这个隐形标记（`manual_window`）已删除，行为完全由上面的设置项决定，可预期、可切换。

## 内部

- 配置新增 `auto_hide`（旧配置缺该字段时按"开启"处理，行为不变），设置页通用区共四个开关
- 删除 `manual_window` 与其相关的窗口事件处理；新增 `set_auto_hide` 命令
- 单测：新增"旧配置缺 `auto_hide` 视为开启"（`cargo test` 现 22 个用例）
- 文档同步：TECH_DESIGN（配置项/命令表/窗口行为）与 PRD（FR-5）

## 安装与升级

- **Linux**：`sudo dpkg -i BeeType_0.2.4_amd64.deb`（覆盖安装后**重启应用**才会加载新二进制）
- 升级不影响绑定关系：主力手机凭 token 自动重连；PC 重启会换新配对码，临时连接需重新扫码
- 手机端无代码改动，APK 可继续用

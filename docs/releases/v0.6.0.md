# BeepType v0.6.0

**这一版是界面与"绑定关系"的打磨：桌面图标留白更协调、多了一个设置页，并修掉两个真实问题——连接状态里凭空冒出的「连接中」倒计时，以及手机重装后扫码绑不回来。**

## 手机界面

- **启动器图标留白**：图标里的图形过去顶满整个可见区，和别的 APP 摆在一起显得挤。现在图形占可见区约 2/3，并清掉了原图底色上的噪点、按图形重新居中
- **新增设置页**：首页右上角加了一个齿轮，**点一下直接进入**（不做菜单中转）。页内是 APP 信息：图标、名称、slogan、版本号、版权。将来有设置项就加在这块信息上面
- **未连接时顶栏不再显示扫码图标**：那个状态的正文本身就是扫码引导页、中间那个大按钮就是扫码入口，顶栏不再重复一个
- **状态胶囊两处改进**：
  - 修掉"已经连上了却显示「连接中 · N 秒」"，以及倒计时结束后那行字还赖着不走的问题；
  - **只有临时连接**会在电脑名后面标「临时」，常用连接不说话（这也让"绑定关系变了"变成一眼可见：电脑端解绑时，手机胶囊立刻出现「临时」）

## 绑定关系

- **手机重装 / 清除数据后再扫码，就能真正重新绑上**：此前电脑端一旦凭硬件指纹"认出老手机"，就直接恢复席位、不下发凭证，而手机本地其实已经什么都没有 → 看着连上了，却什么都存不下，闲置几分钟又被推回扫码页。现在这种情况电脑端会**补发一份新凭证**，绑定随即可靠地落盘
- 已有的绑定关系不受影响；**两端的升级都不需要重新扫码**（与 v0.4.0 是同一把签名）

## 安装

- **PC**：先退出正在运行的程序（否则端口被占），再 `sudo apt install ./BeepType_0.6.0_amd64.deb`
- **手机**：直接覆盖安装 `BeepType_0.6.0_arm64.apk`，**不需要卸载**
- 两个包都属于这一版：PC 端包含绑定修复，手机端包含全部界面改动

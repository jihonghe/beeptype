# BeepType v0.7.0

**这一版把"电脑端的两个行为开关"交到手机手里，并把打字区的手感补齐：点一下打字区就能连、从任何子页面回来光标与键盘自动就位。同时修掉设置页排版与电脑端开关联动的几处小毛病。**

## 手机端

### 设置页

- **新增「电脑端设置」一块**：接收后自动粘贴 / 粘贴后自动发送。开关的标签与说明文字与电脑端设置页**逐字一致**，一眼能看出改的是电脑的行为
  - **只在当前连接是「常用设备」时出现**：临时访客改不了（电脑端也只接受常用设备的修改），索性不给它看
  - 联动与电脑端一致：关掉「接收后自动粘贴」，「粘贴后自动发送」**同时关掉并置灰**，说明变成「请先开启自动粘贴」
- **一端改动，另一端立刻跟上**：手机上拨开关，电脑设置页毫秒级刷新（不再等轮询）；电脑上拨开关，手机这块也实时更新
- **排版收拾干净**：APP 信息**始终贴页面底部**、水平居中；进页面时键盘自动收起、不会再跟进来把内容挤到上半屏；信息块**首帧就在底部**，没有从中间滑下来的动画

### 打字区

- **点一下打字区 = 点「连接」**：断开时点它就开始连——正在连接/重连中不生效（不重置倒计时，也不与轮内在飞的尝试打架）；电脑被别的手机占着而自己是常用设备时，点它接管
- **从设置页或扫码页回来，光标自动回到输入框、键盘自动弹出**：手动点返回与屏幕手势返回都一样
- 断开时的提示合并成一句：「点此区域连接电脑，连上后长按键盘语音键语音输入文字」

## 电脑端

- **修掉开关联动的一个漏洞**：在电脑端关掉「接收后自动粘贴」时，「粘贴后自动发送」只是被置灰、**并没有真的关掉**（运行状态没跟着走），于是再打开粘贴时它又是开着的。现在运行状态与配置始终一致
- 电脑端设置页里那两个开关，在手机端改动后会立刻刷新

## 升级说明

- 新增 `set_prefs` / `prefs` 两条协议消息，成对同步（两个字段都必填）
- **只升级手机也能用**：旧版电脑不认识新消息，手机端就只不显示「电脑端设置」这一块，其余一切照旧
- 想在手机上改电脑的开关：**两端都升到这一版**

## 安装

- **PC**：先退出正在运行的程序（否则端口被占），再 `sudo apt install ./BeepType_0.7.0_amd64.deb`
- **手机**：直接覆盖安装 `BeepType_0.7.0_arm64.apk`，**不需要卸载**
- 两个包都属于这一版：PC 端包含开关联动修复，手机端包含全部界面与手感改动

**BeepType** 把你手机的语音输入变成电脑上的字：按住手机输入法的语音键说话，松开后文字通过局域网直接落在电脑的光标处——该粘贴的粘贴，该回车的回车。

识别用的是**你手机输入法自己的语音能力**（豆包、讯飞、微信、系统语音都行），所以词库、方言、惯用语都是你已经熟悉的那一套。

## 它是什么

- **手机是麦克风，也是识别端**；电脑端什么都不用装：不用装输入法、不用下模型、不用买麦克风
- 文字直接落到**当前光标处**——开着自动粘贴就自动贴，开着自动发送就连回车一起按
- **图片同理**：手机上选图，电脑剪贴板里就是这张图，在聊天框里 Ctrl+V 就发出去了
- 两端在同一个局域网即可，数据只在你的手机和电脑之间

## 什么时候用得上

1. **给 AI 写 prompt** — 想说的话往往很长，打字慢还容易漏
2. **PC 上回消息** — 一边干活一边回微信 / 企业微信，不用切输入法
3. **手机截图要立刻进电脑** — 选图，电脑剪贴板里就有它
4. **电脑没麦克风、或麦克风很差** — 手机就在手边，离嘴更近
5. **口述初稿 / 长命令** — 长邮件、文档、代码注释、终端里的长路径

## 功能

- **扫码配对** — 电脑显示二维码，手机扫一下就连上（临时用一次，或绑定为常用设备）
- **免配重连** — 绑定后打开 APP 自动连；电脑重启、两端换 IP 都不用重新扫码
- **临时接入可续连** — 临时手机被系统杀掉后，默认 5 分钟内重开 APP 即可自动连回
- **单席位与接管** — 一台电脑同时只服务一部手机；常用设备点「连接」即可接管
- **自动粘贴 / 自动发送** — 文字落进光标处并可自动回车；**按住语音键期间一个字都不会发**，松手后整段一次发出
- **图片传输** — 手机选图（可多选）→ 电脑剪贴板里的图片 → 在支持粘贴图片的输入框里自动贴出来；先选后发、可逐张删、可继续加
- **零账号 · 零云端** — 局域网直连，不经任何服务器；**内容不落盘**（只在内存与剪贴板里流转）
- **跨平台** — PC 端 Linux（X11）/ Windows / macOS；手机端 Android

## 快速开始

**下载安装**：

| 平台 | 文件 |
|------|------|
| Linux | `.deb` 或 `.AppImage` |
| Windows | `.msi` |
| macOS | `.dmg` |
| Android | `.apk` |

前往 [GitHub Releases](https://github.com/jihonghe/beeptype/releases) 下载；想从源码构建、或搭开发环境，见 [CONTRIBUTING.md](CONTRIBUTING.md)。

**三步用起来**：

1. 电脑上启动 BeepType → 系统托盘出现图标，点开主窗口
2. 手机上打开 BeepType → 点顶部扫码按钮 → 扫电脑上的二维码（可勾选「记住这台手机」）
3. 在手机上按住输入法的语音键说话 → 松开 → 文字出现在电脑光标处
   - 发图片：点输入框下方的「添加图片」选图，与文字一起发到电脑

## 平台支持

| 平台 | 自动粘贴 | 自动发送 | 备注 |
|---|---|---|---|
| Linux X11 | ✅ | ✅ | 原生支持 |
| Linux Wayland | ❌ | ❌ | Wayland 禁止后台进程输入注入，退化为手动 Ctrl+V（文字与图片都能用） |
| Windows 10+ | ✅ | ✅ | |
| macOS 12+ | ✅ | ✅ | |
| Android 8.0+ | — | — | 手机端 |
| iOS | — | — | 未支持，见路线图 |

## 路线图

- [ ] **手机端输入控制台** — 历史记录、编辑后重发、失败不丢原文
- [ ] **自定义键位** — 粘贴键与发送键可自选（普通应用与终端各一组；默认 Ctrl+V / Enter，终端内不自动发送）
- [ ] **iOS 适配** — 原生通道代码已就绪，待真机验证与分发
- [ ] **Linux Wayland 会话的自动粘贴**（探路）— 触发条件：自己的会话切到 Wayland，或出现真实用户需求

已完成：扫码配对与绑定、临时接入续连、自动粘贴 / 自动发送、**松手才发**（v0.7.1）、**图片传输**（v0.8.0）。

> 更详细的路线图、竞品地图与明确**不做**的事，见 [`docs/PRODUCT.md`](docs/PRODUCT.md)；发版前两者会对齐。

## 安全与隐私

- 配对码与设备凭证都是 32 字节随机串，只存 SHA-256；配对码一次性、5 分钟过期
- 局域网直连，**不经任何外部服务器**；发出的内容**不落盘**（PC 端只写系统剪贴板与内存）
- 不做账号、不做云中继、不做遥测
- 细节与已知边界见 [SECURITY.md](SECURITY.md)
